Method

  1. List every Active FIPS 140-3 certificate from the CMVP validated modules search.
  2. Fetch each certificate page and read the Approved Algorithms section. A module counts when an entry starts with “ML-DSA” or “ML-KEM”.
  3. Pull the validations from the CAVP validation search (each operation queried separately, all result pages) and cross-check the module entries against them.
  4. Fetch each referenced CAVP validation for parameter sets, signature interfaces or KEM functions, and operational environments.
  5. Match unattached CAVP validations to the CMVP Modules In Process list by vendor and module name.
Caveats. Modules in process are not validated, and historical or revoked certificates are excluded. Check the Security Policy for the exact services and operational environments covered. Modules mentioning these algorithms only in allowed or non-approved text: 0.
